## Terraform aws providers

A simple notes about terraform providers.

### What is a Provider?

- **Provider** in terraform is basically know as a program or code that knows how to talk to specific technology or platform.
- **Provider** actually gives us the access to the entire whole API of the aws.
- **Providers** are not included in the terraform download.

**Best Practices:**
- Don't hard-core credentials directly in the configuration file(main.tf) of terraform.
- Config files will be hosted in a version control system, e.g. Git repo.

## First create a main file with .tf extension and write the below code in it.

```bash
provider "aws" {
    region = "eu-west-3"
    access_key = "your aws access key"
    secret_key = "your secret key"  
}
```
Then go to the path of the file in terminal and execute the below commands.

```bash
terraform init
```

**Terraform init** - It initializes a working directory and installs providers defined in the terraform configuration file.

When we execute the above command then the below hidden folder and file will be generated by terraform.
- .terraform folder - Installed provider files are stored in this folder.
- .terraform.lock.hcl - This file keeps a track of which provider is installed and which version we have.
